## Pokemon API Challenge!

In this project, I designed a figma prototype that allows a user to enter a name of a pokemon or pokedex number entry to see that pokemons base stats, 
shiny form, all moves, possible encounter locations and evolution line within the main line games.
The user can add pokemon to their favorites list and toggle the fav sidebar tab to view and click on pokemon names. Favorite pokemon names will be saved via local storage and 
application will be responsive for this build!
